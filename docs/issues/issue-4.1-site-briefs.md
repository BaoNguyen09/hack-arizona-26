# Issue 4.1: LLM-Generated Site Assessment Briefs

## Scope

- Create a prompt template for structured site payloads
- Integrate GPT-4o-mini or equivalent model
- Display a strict, structured 150-word brief in the site investigation panel

## Acceptance Criteria

- Prompt template is deterministic and guarded against unsupported claims
- Generated briefs are cached or rate-limited for demo stability
- UI clearly distinguishes modeled metrics from generated narrative
